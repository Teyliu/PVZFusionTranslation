# 3.8 → 3.9 Update Changes

> Báo cáo so sánh tự động giữa `BepInEx/AS/3.8/` và `BepInEx/AS/3.9/` (decompiled `Assembly-CSharp`).
> Phương pháp: quét toàn bộ cây `.cs`, so sánh tên class + tên file + base class + text component usage.

## Tổng quan

| Metric | 3.8 | 3.9 | Delta |
|---|---|---|---|
| File `.cs` (Assembly-CSharp + Core) | 2488 | 2651 | **+163** |
| Class declaration (kể cả trùng tên nhiều file) | 2405 | 2554 | +149 |
| Tên class unique | 2106 | 2188 | **+82** |
| File mới (3.9-only) | — | 174 | — |
| File bị xóa (3.8-only) | — | 11 | — |
| Class bị xóa tên | — | 11 | — |
| Class mới tên | — | 93 | — |

**Trọng tâm update 3.9:**
1. Hệ thống **RogueShooting** (roguelike mode) mở rộng mạnh: `GameLevel/RogueShooting/` 107 → 167 file (+60).
2. SDK mới: **OpenBLive** (Bilibili live interaction, 58 file) + **NativeWebSocket** (15 file).
3. ~30 class plant/bullet mới + 48 buff `Shooting_*` mới cho Rogue mode.
4. Hệ thống damage popup mới (`NumberPopManager`/`NumberPop`) thay thế `DamagePopup`.

## 6. Hệ quả cho Plugin Modified-Plus

1. **`DamagePopup` biến mất** → nếu plugin từng patch `DamagePopup`, phải chuyển sang `NumberPop`/`NumberPopManager`.
2. **`TextHelper` biến mất** — nếu plugin patch nó, bỏ (không có thay thế).
3. **Bullet base class đổi** (`Bullet_cactus`, `Bullet_threeSpike`) — nếu plugin patch theo base class cũ, cập nhật.
4. **49 buff `Shooting_*` Rogue mới** + `Curse_*` — cơ hội mở rộng patch Rogue mode.
5. **OpenBLive/NativeWebSocket mới** — game giờ có kết nối Bilibili live + WebSocket (liên quan TCP client của plugin? cần kiểm tra port).
6. **Text component phổ biến**: đa số dùng `TextMeshProUGUI` (120/160). Plugin patch text nên ưu tiên TMPUGUI.
